## Overview

This module brings the previous concepts together into a structured AI security assessment.

## Topics

- AI security testing lifecycle & red teaming
- Security test planning & threat-based testing
- LLM / agent / RAG evaluation
- Attack simulation & vulnerability validation
- Risk classification & security reporting
- Remediation planning
- AI application hardening
- Security-control validation & re-testing

## The Lifecycle

```text
Plan  →  Test  →  Document Finding  →  Mitigate  →  Re-Test  →  Report
```

## Hands-on

- Create an AI red-team test plan
- Build an attack scenario
- Execute controlled security tests
- Record findings and evidence
- Analyze technical and business impact
- Recommend remediation
- Implement security controls
- Re-test after mitigation

## Key Takeaways

1. A finding isn't done until it's been re-tested against the actual fix.
2. Continue to **[Module 16](./module-16-ai-red-teaming.md)** for the complete engagement methodology.
